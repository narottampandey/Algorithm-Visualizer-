# Algorithm Visualizer

Visualize algorithms step by step and see useful details like category, complexity, and common use-cases.

## Included visualizations

- Bubble Sort
- Binary Search
- Dijkstra's Algorithm

## Run locally

Because this is a static web app, you can run it with any simple local server.

### Option 1: Python

```bash
python3 -m http.server 8080
```

Open: `http://localhost:8080`

### Option 2: open file directly

Open `/home/runner/work/Algorithm-Visualizer-/Algorithm-Visualizer-/index.html` in your browser.
